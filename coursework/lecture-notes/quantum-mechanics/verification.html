Question wording and numbering

All 100 numbered manuscript entries have a corresponding web question and worked solution. Part A and Part B numbering restarts within each assignment. Their order is retained, rather than renumbered 1–100.

Original scans remain unavailable for this audit. The manuscripts describe their questions as transcriptions, sometimes lightly regularized. The web edition therefore labels them “Question as transcribed in manuscript.” Exact wording, source numbering, and omissions relative to the original handouts cannot yet be independently verified.

  • Assignment II A5: “Problem 3.27 Griffiths” does not specify an edition. The main solution follows the second-edition interpretation in the manuscript. Full supporting derivations for the first- and third-edition interpretations are also retained; they are not counted as extra assigned problems.
  • Assignment IV A4: the manuscript discusses the spherical-harmonic phase convention needed to interpret the printed conjugation identity. Read that qualification with the solution.
  • Assignment V: the manuscript records an overlapping source block headed “Assignment V–Part I” (A1–A4, B1–B5), and an expanded block headed “Assignment IV” (A1–A15, B1–B10). “V” is the compilation’s consolidated label. The original grouping remains unresolved; no additional Assignment V–Part II has been verified.

Mathematical review

Structural checks confirm 100 manuscript headings in order and 647 display-equation blocks retained in numbered problems, ignoring labels, spacing and alignment wrappers. Equation-transfer checks compare the web content with the retained LaTeX manuscripts. They do not prove that every derivation is mathematically correct. Detailed independent review of all assumptions, domains, boundary conditions, algebra and conclusions remains outstanding.

Source discrepancies and unspecified parameters are retained as qualifications. Numerical illustrations of the finite well use the manuscript’s explicitly chosen dimensionless depth P = 4, rather than suggesting it was specified by the assignment.

PDF availability

The referenced chat reports a file named QM_All_Assignments_I-V_Complete_150pages.pdf and a combined LaTeX/PDF ZIP. Neither binary file is present in the repository or available to this audit. No download link is presented as working until the actual file is supplied.

Each assignment offers “Expand all” and “Print / Save as PDF” for a browser-generated copy. That copy is a web printout, not the original compiled 150-page manuscript. The five editable LaTeX files remain downloadable.
